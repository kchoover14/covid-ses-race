## Summary

This project examines whether socioeconomic status and race predict self-reported chemosensory ability and COVID-19 diagnosis-seeking behavior, using two independently collected samples (a paid, low-income-targeted Qualtrics survey and an opportunistic FormR survey) joined into a single dataset. A preregistered analysis found no significant relationship between race and chemosensory outcomes in either sample, and an exploratory follow-up -- built after finding that self-reported ability was significantly confounded by individual differences in odor awareness -- tested an awareness-adjusted ability measure against two independently constructed socioeconomic status measures. Both measures showed a significant, consistent, and unexpected pattern: higher socioeconomic status was associated with worse self-reported olfactory ability, the reverse of the study's original prediction, while diagnosis-seeking due to smell/taste loss showed no significant socioeconomic differences in either sample.
